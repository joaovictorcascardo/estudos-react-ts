# Loja Virtual (React + TypeScript)

Primeiro estudo de React com TypeScript: uma vitrine de produtos que mostra preço, preço com desconto e situação do estoque.

## O que pratiquei

- Componentes funcionais e JSX
- Tipagem com `interface` (Produto com campo opcional `precoDesconto`)
- Renderização de listas com `.map()` e `key`
- Renderização condicional (produto sem estoque fica cinza, preço promocional só aparece quando existe)

## Tecnologias

- React 19
- TypeScript
- Vite

## Como rodar

```bash
npm install
npm run dev
```
